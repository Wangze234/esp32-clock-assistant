# 阶段 2：WiFi + NTP 时钟

> 目标：断电重启后能自动联网、自动对时，串口每秒打印一行准确的北京时间。
> 预计耗时：30 分钟（大部分时间在反复试 WiFi 和 NTP）。
> 前置：阶段 0 完成；阶段 1 的屏幕已能正常显示（2026-11-08 恢复）。
> 屏幕配置复用 `../stage1_display/User_Setup.h`，必须先把它覆盖到 TFT_eSPI 库里。

---

## 0. 本阶段做了什么

1. **联网 + 对时**：连 WiFi、从 NTP 取北京时间，串口每秒打印一行（先单独验证这条链路）。
2. **画面上屏**：屏幕已恢复正常（2026-11-08），所以直接把时钟画到屏上。

屏幕布局（横屏 320×240，参照 DUKA 那种 LCD 表的样式：浅灰底 + 深色字）：

```
┌────────────────────────────────────────┐
│ 11/08  Sun                    ▁▃▅█     │  ← 顶栏 40px：左日期(深灰)，右 WiFi 图标
├────────────────────────────────────────┤  ← 分隔线
│                                        │
│              18:40:47                  │  ← 黑色 7 段数码管字体（字体 7），每秒刷新
│                                        │
└────────────────────────────────────────┘
```

| 元素 | 说明 |
|---|---|
| 背景 | `BG_COLOR = 0xC618` 浅灰；改 `0x4208` 即变深灰底（配 `FG_COLOR = TFT_WHITE` 是深色主题） |
| WiFi 图标 | 右上角 4 根小柱，RSSI ≥-60 亮 4 根、≥-70 亮 3 根、≥-80 亮 2 根、更弱 1 根；**断网时 4 根全浅 + 红色叉** |
| 日期 | `%m/%d  %a` → `11/08  Sun`，只在日期变化时重画 |
| 刷新 | 时间每秒重画；图标只在信号档位变化时重画，避免闪烁 |

> TFT_eSPI 内置字体只支持 ASCII，画不了"周日"，所以屏幕上用 `Sun`；中文要等阶段 5 的 LVGL 字库。
> 串口输出仍是中文（`周日`），两者是一套数据。

## 1. 填 WiFi 账号密码

1. 打开本目录下的 `secrets.h`（已按模板生成，已被 .gitignore 排除，**不会进 git**）
2. 把这两行改成你自己的：

```cpp
#define WIFI_SSID       "你的WiFi名称"
#define WIFI_PASSWORD   "你的WiFi密码"
```

> ⚠️ 注意事项：
> - 只支持 **2.4GHz** 频段。ESP32 不认 5GHz 的 WiFi，如果家里是双频合一，先试；连不上就把路由器 2.4G 单独开一个 SSID。
> - 名称和密码用英文双引号包起来，保留引号。
> - **不要把 secrets.h 发给任何人，也不要提交到 git**（`.gitignore` 已经挡住，但不代表可以随便贴）。

## 4. 验收标准

- [x] 上电后 10 秒内连上 WiFi，串口打印出 IP 和 RSSI
- [x] 打印的时间与手机时间**误差不超过 1 秒**
- [x] 秒数连续跳动，不重复、不跳秒
- [x] 星期几正确（`周六` / `周日` 别搞反）
- [x] **屏幕上显示时钟**，秒级刷新，底栏显示 RSSI 和 NTP 状态
- [x] **拔掉路由器电源再恢复**：串口打印 `[wifi] lost`，之后自动重连成功
- [x] 连续跑 10 分钟，时间不漂移
- [x] **断网期间表盘不卡**（秒数照常跳）

## 5. 故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `WiFi: FAILED (status 1)` | 一直连不上 | 检查 SSID/密码；确认是 **2.4GHz** 网络；把手机热点打开试一下 |
| `WiFi: FAILED (status 6)` | 密码错 / 找不到该 SSID | 重新核对 secrets.h |
| `NTP: TIMEOUT` | DNS 或网络不通 | 先确认能 ping 通 `ntp.aliyun.com`；换手机热点再试 |
| 时间差 8 小时 | 时区没设 | 确认 `GMT_OFFSET_SEC = 8 * 3600` |
| 时间正确但星期不对 | 时区导致 tm_wday 偏移 | 同上，检查时区后再看 |
| 秒数跳动不均匀 | WiFi 省电模式 | 已用 `WiFi.setSleep(false)`，不要删掉 |
| 一直打印 `[time] not synced yet` | 连上了 WiFi 但 DNS/NTP 不通 | 换手机热点试；确认 `ntp.aliyun.com` 能解析 |
| **断网后表盘定住不动** | 用了阻塞式 `while` 等连接 | 本目录代码已是非阻塞状态机（`wifiService()`），不要改回 while 等待 |
| 反复 `sta is connecting, cannot set config` 且连不上 | 上一次连接尝试还没结束就再次 `WiFi.begin()` | 已加 `WiFi.disconnect(false, false)` 清理残留状态 |
